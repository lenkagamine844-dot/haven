Notification keys

This page makes the pair of keys Haven’s notifications need. The keys are made here in your browser and never sent anywhere.

Make them once. If you make new ones later, every device has to turn notifications on again.

Public key

Goes into push-config.js on GitHub. It’s fine for people to see this one.

Private key

Goes only into Cloudflare as the secret VAPID_KEY. Don’t put it on GitHub or share it.

Paste both somewhere safe (like Notepad) before closing this page. Closing it forgets them.
